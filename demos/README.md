# demos

One directory per milestone (plan 11, P109). Each README names the exact
commands that produced its files, and every artifact in here was written
by the built CLI.

| Directory | Milestone | What it shows |
|---|---|---|
| `e0-carriers/` | E0, the spike | the two survival tables and the impulsos measure, all UNMEASURED, with the procedure |
| `e1-two-files-one-document/` | E1, the value | one document rendered into a `.mid` and a `.it`, both read back as derived skeletons, all three printing the same tempo map |
| `e2-exact-import/` | E2, the pacer door | the landing proof's output, three scores through pacer's own CLI, the trigger lanes firing |
| `e3-one-file/` | E3, the superset | a native timeline built to both kinds and dumped back essence-exact, then a foreign edit and the reconciliation table |
| `e4-packed/` | E4, the studio | the `TMPU` payload kind, reserved and waiting on expansible-player X1 |

`e4-studio/` does not exist. pstudio is not a host (ruled 2026-09-20), so
the timeline pane and the transport display are dropped rather than
pending.

Three things every demo says out loud rather than quietly: what was
measured, what was not, and why. The unmeasured items all point at
`conformance/CHECKLIST.md`, which is the file to edit when a run happens.
